# gif-search Specification

## Purpose

Даёт поиск и трендовую выдачу GIF и прозрачных стикеров из внешних каталогов (GIPHY, KLIPY) прямо в попапе.

## Requirements

### Requirement: Доступные источники
Система SHALL показывать источники по заданным ключам: при ключе GIPHY — «GIPHY» (гифки) и «GIPHY стикеры», при ключе KLIPY — «KLIPY». Если ни одного ключа нет, режим «GIF» MUST показывать подсказку и кнопку, открывающую настройки, вместо поиска и трендов; недавние GIF при этом остаются. Если источников больше одного, система MUST показывать переключатель между ними.

#### Scenario: Нет ключей
- **WHEN** пользователь открывает режим «GIF» без сохранённых ключей
- **THEN** показан текст «Для поиска GIF нужен API-ключ GIPHY или KLIPY» и кнопка «Открыть настройки», по нажатию открывается экран «Настройки»

#### Scenario: Оба ключа
- **WHEN** сохранены ключи GIPHY и KLIPY
- **THEN** над выдачей есть переключатель «GIPHY», «GIPHY стикеры», «KLIPY»

### Requirement: Тренды и поиск
При пустом запросе система SHALL показывать раздел недавних GIF (если они есть), а под ним — трендовую выдачу выбранного источника. При вводе запроса поиск MUST выполняться через 350 мс после последнего нажатия клавиши; при непустом запросе недавние GIF не показываются. Выдача показывается в две колонки с сохранением пропорций превью, в порядке выдачи: каждый следующий элемент встаёт в более короткую колонку, при равенстве — в левую. Подгрузка следующей страницы MUST NOT сдвигать уже показанные элементы. В документе присутствуют только элементы видимой области и небольшой запас вокруг неё; GIF вне экрана MUST NOT проигрываться.

#### Scenario: Ввод запроса
- **WHEN** пользователь вводит «кот» и перестаёт печатать
- **THEN** через 350 мс выдача заменяется результатами по запросу «кот», раздела недавних нет

#### Scenario: Пустой результат
- **WHEN** по запросу ничего не найдено
- **THEN** показан текст «Ничего не нашлось»

#### Scenario: Недавние перед трендами
- **WHEN** пользователь отправлял GIF и открывает режим «GIF» с пустым запросом
- **THEN** сверху раздел недавних GIF, под ним тренды выбранного источника

#### Scenario: Порядок выдачи
- **WHEN** показана выдача из GIF одинаковой формы
- **THEN** первый GIF слева вверху, второй справа вверху, третий слева под первым

#### Scenario: Длинная выдача
- **WHEN** пользователь подгрузил 10 страниц выдачи и прокручивает её
- **THEN** в документе отрисованы только GIF видимой области и запаса, прокрутка идёт без подвисаний

### Requirement: Подгрузка при прокрутке
Система SHALL подгружать следующую страницу выдачи (по 24 элемента), когда до конца списка остаётся меньше 200 px, пока источник сообщает о наличии следующей страницы. Ответы на устаревшие запросы (сменился запрос, источник или вкладка) MUST NOT попадать в выдачу.

#### Scenario: Прокрутка до конца
- **WHEN** пользователь прокручивает выдачу до конца
- **THEN** под текущими элементами появляются следующие 24

#### Scenario: Смена запроса во время загрузки
- **WHEN** пользователь меняет запрос, пока грузится предыдущий
- **THEN** в выдаче только результаты нового запроса

### Requirement: Качество превью и отправки
Для превью система SHALL использовать облегчённые варианты GIF источника, а для отправки — вариант не больше примерно 2 МБ (downsized у GIPHY, gif у KLIPY).

#### Scenario: Отправка из GIPHY
- **WHEN** пользователь кликает на GIF из GIPHY
- **THEN** отправляется вариант downsized, а не оригинал

### Requirement: Атрибуция и фильтрация
Под выдачей система MUST показывать атрибуцию источника («Powered by GIPHY» или «Powered by KLIPY»). Запросы MUST содержать фильтр контента: rating `pg-13` для GIPHY, contentfilter `medium` для KLIPY.

#### Scenario: Выдача GIPHY
- **WHEN** показана выдача GIPHY
- **THEN** под ней есть подпись «Powered by GIPHY»

### Requirement: Ошибки источника
При ошибке запроса система SHALL показать в статусе попапа текст ошибки с префиксом «GIF:». При ошибке подгрузки следующей страницы уже загруженная выдача MUST сохраняться.

#### Scenario: Неверный ключ
- **WHEN** ключ GIPHY недействителен и API возвращает 401 или 403
- **THEN** в статусе показано «GIF: HTTP 401 …» или «GIF: HTTP 403 …»

### Requirement: Язык выдачи
Запросы к источникам GIF SHALL передавать язык интерфейса (см. `localization`), чтобы поиск и тренды учитывали язык
пользователя: GIPHY — в поиске GIF и стикеров, KLIPY — в поиске и трендах. Смена языка между загрузками страницы MUST
давать выдачу на новом языке без очистки недавних GIF. Если источник язык не учитывает, выдача MUST оставаться
рабочей.

#### Scenario: Поиск на русском
- **WHEN** интерфейс на русском и пользователь ищет «кот» в GIPHY
- **THEN** запрос поиска к GIPHY уходит с языком `ru`

#### Scenario: Тренды KLIPY на английском
- **WHEN** интерфейс на английском и пользователь открывает KLIPY с пустым запросом
- **THEN** запрос трендов к KLIPY уходит с английской локалью

#### Scenario: Недавние после смены языка
- **WHEN** пользователь отправлял GIF при русском интерфейсе и открыл amo на английском
- **THEN** недавние GIF на месте, тренды и поиск запрашиваются на английском
