## Why

(issue #48)

При открытии чата, пока файл стикера скачивается, amo показывает на его месте серую заглушку со спиннером — в
пузыре и в размере обычного фото (до 420 px по стороне). Через 0,1–3 с картинка загружается, и сообщение прыгает:
пузырь пропадает, стикер сжимается до 208 px. Заглушка есть при любом открытии чата, даже когда файл уже в кэше amo.

Причина — в заглушке нет `<img>`, а с ним и `alt` с именем файла: по разметке наш стикер не отличить от обычного GIF,
кроме inline-размера. Стиль amo stickers узнаёт сообщение только по `alt` и до загрузки картинки не срабатывает.
Размер заглушки amo выставляет сразу, но inline-стилем, который CSS не прочитает числом. Средствами расширения это не
исправить, поэтому нужна правка на стороне amo: имя файла amo знает из данных сообщения ещё до скачивания, а размер
контейнера уже посчитан — их достаточно отдать в разметку.

## What Changes

- **amo web** (отдельный PR в репозиторий amo): контейнер картинки медиа в ленте несёт имя файла атрибутом
  `data-file-name` и свой размер — те же числа, что amo пишет в его inline `width` / `height`, — CSS-переменными
  `--media-w` / `--media-h` (числа в пикселях) — и в заглушке, и после загрузки.
- **amo stickers**: сообщение узнаётся и по `alt` картинки, и по `data-file-name` контейнера. Заглушка нашего
  сообщения — без пузыря, хвоста и подложки; заглушка стикера — сразу в итоговом размере (вписан в 208×208 CSS px,
  без увеличения), без серой заливки, со спиннером amo. Загрузка картинки не меняет размер и положение стикера.
- Пока amo не несёт атрибута и переменных, поведение прежнее: заглушка в пузыре, после загрузки — стикер без пузыря.
- Стенд `dev/harness.html` показывает заглушку с разметкой amo и её смену картинкой.

## Capabilities

### New Capabilities

— нет.

### Modified Capabilities

- `chat-message-style`: распознавание своего сообщения — ещё и по имени файла на контейнере картинки; новое
  требование к сообщению, картинка которого ещё загружается.

## Impact

- `src/core/amoDom.ts` — селекторы и текст `MESSAGE_CSS`; знание о DOM amo остаётся в нём одном.
- `dev/harness.html` — состояние загрузки у сообщения ленты.
- amo web — правка компонента картинки медиа ленты, отдельный PR и релиз amo; без него правка amo stickers ничего не
  меняет, но и не ломает.
- Версия amo stickers — патч (`0.11.1` → `0.11.2`).
- Отправка, имя файла и пикер не меняются. Мерцание при закрытии панели вложений после отправки — отдельная задача.
