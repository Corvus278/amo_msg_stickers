## Why

Обложка пака на вкладке полосы разделов рисуется крупнее холста и обрезается, если плотность пикселей экрана
(`devicePixelRatio`) сменилась, пока попап открыт: окно переехало на другой монитор, сменился масштаб страницы,
эмуляция DevTools при съёмке скринов (issue #57). Кэш битмапов обложек одного открытия хранит кадр по id стикера,
без размера, и холст новой стороны получает кадр, декодированный под старую. Уменьшение плотности даёт обложку
крупнее и обрезанную, увеличение — мельче квадрата.

## What Changes

- Кадр обложки из кэша открытия берётся по стикеру и стороне холста: холст новой стороны получает кадр своего
  размера, а не кадр прежней стороны.
- Тест кэша: тот же стикер с другой стороной декодируется заново, с той же — отдаётся из кэша.
