## Why

Стикер, отправленный из пикера, в ленте amo выглядит как обычное фото: пузырь с градиентом, тенью, хвостом и
размытой подложкой, которая просвечивает сквозь прозрачность GIF, и размер до 420 px — вдвое крупнее стикера в
Telegram. Публичного API и признака «стикер» у сообщения amo нет, поэтому своё сообщение нужно пометить так, чтобы
метку увидел и получатель, и стилизовать его на стороне клиента (issue #21).

## What Changes

- Имя отправляемого файла несёт метку: `[метка.]amostk.k-<sticker|gif>[.<ключ>-<значение>]*.gif`. amo доставляет
  имя получателю в `alt` картинки сообщения, GIF — без перекодирования.
- Вид в имени: `k-sticker` — стикер из пака (свой или из Telegram), `k-gif` — GIF из поиска GIPHY / KLIPY. Для
  «Недавних» вид берётся от исходного элемента.
- Метка для людей — эмодзи Telegram-стикера, подпись своего стикера или название GIF: вычищается от `.`, `/`,
  управляющих и bidi-символов, обрезается до 32 графем (не больше 128 байт), пустая не пишется.
- Модуль имени файла — сборка и разбор чистыми функциями, с юнит-тестами. Отправка на всех путях (пак, поиск,
  «Недавние») получает имя из него вместо `sticker.gif` / `gif.gif`.
- Подпись своего стикера сохраняется вместе с ним — из неё строится метка.
- Глобальный `<style>` в документе amo, вставляется один раз при старте: у сообщения с нашей картинкой нет пузыря,
  хвоста, тени, скругления и размытой подложки; оверлей времени и статуса остаётся. Стиль действует только на
  медиа сообщения в ленте: ответ с цитатой стикера, пересланный стикер, просмотрщик и список чатов не меняются.
- Стикер (`k-sticker`) в ленте вписан в 208×208 CSS px с сохранением пропорций, место под картинку ограничено
  целиком; GIF из поиска — в прежнем размере. Стикер меньше 208 px не увеличивается.
- Стенд `dev/harness.html` показывает отправленное разметкой сообщения amo, чтобы стиль проверялся без живого amo.

Картинки без метки, в том числе уже отправленные `sticker.gif`, выглядят как раньше. Клиенты без расширения или
userscript показывают обычный пузырь в прежнем размере — это приемлемо.

## Capabilities

### New Capabilities

- `chat-message-style`: вид отправленных amo stickers сообщений в ленте чата — без пузыря и подложки, размер стикера
  как в Telegram; распознавание своего сообщения по метке в `alt`.

### Modified Capabilities

- `sticker-sending`: у отправляемого файла — имя в формате метки вместо фиксированного `sticker.gif`.
- `custom-stickers`: подпись своего стикера сохраняется вместе с ним.

## Impact

- Код: новый модуль имени файла (`src/core/fileName.ts` + типы), `sender.ts` (`toGifFile`, `toCheckedGifFile`
  принимают готовое имя), `app.ts` (имя на каждом пути отправки, вставка `<style>` в `start()`), `amoDom.ts`
  (селекторы ленты и CSS сообщения), `db.types.ts` (необязательная подпись у `StickerRec`, без смены версии
  IndexedDB), `useStickerDraft` (сохраняет подпись).
- Тесты: `tests/fileName.test.ts`, правка `tests/sender.test.ts`.
- Стенд `dev/harness.html`, документация `CLAUDE.md` и `README.md`.
- Версия — минор: `0.8.0` в `package.json`, `manifest.json` и заголовке userscript.
- Зависимостей не добавляется. Риск — вёрстка ленты amo: часть классов — хэши CSS-модулей, точные селекторы
  подбираются в живом amo.
