## Why

Пикер собран из DOM вручную: 900 строк класса `Picker` с `h()`, `replaceChildren` на каждый рендер, состоянием в полях и
отдельной строкой CSS на 160 строк. Каждая новая вкладка или форма добавляет ручную синхронизацию DOM и состояния, а
палитра amo продублирована литералами в CSS-переменных. Перевод на Preact и Tailwind с токенами amo делает UI
декларативным и привязывает цвета, размеры и шрифты к той же системе токенов, на которой свёрстан сам amo.

## What Changes

- UI пикера переписывается на Preact: компоненты, хуки, контекст вместо класса `Picker` и `h()`.
- Стили пикера — Tailwind 3 с темой из дизайн-токенов amo (палитра, размеры шрифта, радиусы, тени, отступы,
  длительности). CSS собирается при сборке и вставляется в Shadow DOM пикера; `styles.ts` удаляется.
- Тёмная тема — через `dark:`-варианты Tailwind, а не через переопределение CSS-переменных.
- Сборка: esbuild собирает `.tsx` с JSX Preact и компилирует CSS Tailwind в обеих целях (расширение и userscript),
  в том числе в `watch`.
- Иконки вкладок — компоненты вместо svg-строк через `innerHTML`.
- Поведение пикера для пользователя не меняется: те же вкладки, формы, тексты, сценарии отправки, импорта, создания
  стикеров и настроек. Внешний вид сохраняется; допустимы расхождения на уровне округления к ближайшему токену amo.
- Кнопка стикеров в поле ввода остаётся как есть: она живёт в DOM amo и использует его собственные классы.
- Версия поднимается до 0.2.0.

## Impact

- **Код:** `src/core/ui/` переписывается целиком (`picker.ts`, `styles.ts`, `icons.ts`, `picker.types.ts` → дерево
  `.tsx`-компонентов и хуков); `src/core/app.ts` — только точка создания пикера, контракт открытия, закрытия, темы и
  `onSend`/`onClose` сохраняется.
- **Сборка:** `build.mjs` (JSX, плагин CSS Tailwind), `tsconfig.json` (`jsx`, `jsxImportSource`), новый
  `tailwind.config.ts` с токенами amo.
- **Зависимости:** `preact` (runtime), `tailwindcss@3`, `postcss` (dev).
- **Размер бандла:** +~4 КБ Preact (gzip) и CSS только используемых утилит взамен ручного CSS.
- **Не затрагивается:** ядро (`convert`, `db`, `sender`, `sources`, `amoDom`), `Host`, IndexedDB, протокол
  content ↔ background.
