## MODIFIED Requirements

### Requirement: Сетевые запросы в обход CORS страницы
Запросы к внешним API и CDN SHALL выполняться в обход CORS страницы, чтобы не зависеть от CORS-заголовков сервисов: в расширении — из фонового service worker, в userscript — через сетевой API менеджера userscript-ов (`GM_xmlhttpRequest` или `GM.xmlHttpRequest`). Ошибки HTTP MUST возвращаться в интерфейс с кодом статуса и началом тела ответа. Запросы userscript через API менеджера MUST уходить без cookie целевых сайтов. Заголовок userscript MUST перечислять в `@connect` только хосты сетевой политики: `api.telegram.org`, `giphy.com`, `klipy.com`.

#### Scenario: Telegram без CORS
- **WHEN** Telegram API не отдаёт CORS-заголовки
- **THEN** импорт в расширении всё равно работает

#### Scenario: Скачивание файла стикера Telegram в userscript
- **WHEN** в userscript, установленном в Tampermonkey, пользователь импортирует пак Telegram, а ответ на скачивание файла стикера (`api.telegram.org/file/bot…`) приходит без `Access-Control-Allow-Origin`
- **THEN** файлы стикеров скачиваются, импорт доходит до конца, импортированный стикер отправляется в чат

#### Scenario: Ошибка HTTP в userscript
- **WHEN** запрос userscript через API менеджера получает ответ со статусом 404
- **THEN** операция завершается ошибкой, текст которой содержит `HTTP 404` и начало тела ответа

#### Scenario: Сетевая политика в userscript
- **WHEN** userscript запрашивает адрес вне сетевой политики либо ответ API менеджера пришёл с итоговым адресом вне политики после редиректа
- **THEN** запрос завершается ошибкой «Адрес вне списка разрешённых», данные ответа ядру не передаются

#### Scenario: Лимит размера в userscript
- **WHEN** userscript скачивает файл с лимитом, а тело ответа больше лимита (с `Content-Length` или без него)
- **THEN** загрузка обрывается, не дочитывая остаток, операция завершается ошибкой «Файл больше N МБ»

### Requirement: Userscript
Система SHALL поставляться как самодостаточный userscript (`dist/amo-stickers.user.js`) с тем же поведением, что и расширение. Он работает в менеджерах userscript-ов (Tampermonkey и т. п.). В менеджере, который это поддерживает, userscript MUST выполняться в изолированном мире, а не в мире страницы: скрипты страницы MUST NOT получать доступ к коду ядра, к API менеджера и к настройкам. Если скрипт подключён на страницу без менеджера и API менеджера недоступно, userscript MUST работать через прямой `fetch` со страницы и `localStorage`. Повторное подключение скрипта на той же странице MUST NOT создавать второй экземпляр.

#### Scenario: Запуск в менеджере userscript-ов
- **WHEN** пользователь устанавливает скрипт в Tampermonkey и открывает web.amo.tm
- **THEN** в поле ввода появляется кнопка стикеров, в консоли строка `[amo-stickers] started (userscript)`

#### Scenario: Изоляция от страницы
- **WHEN** скрипт страницы amo обращается к `GM_xmlhttpRequest`, `GM_getValue` или к глобальным объектам userscript
- **THEN** они для него не определены

#### Scenario: Подключение без менеджера
- **WHEN** `dist/amo-stickers.user.js` подключён на страницу напрямую, без менеджера userscript-ов
- **THEN** кнопка стикеров появляется, сетевые запросы идут прямым `fetch` со страницы, настройки хранятся в `localStorage`

#### Scenario: Двойное подключение
- **WHEN** скрипт подключён на странице дважды
- **THEN** у каждого поля ввода по-прежнему одна кнопка стикеров

### Requirement: Настройки
Система SHALL хранить ключ GIPHY, ключ KLIPY и токен Telegram-бота на вкладке «Настройки» в хранилище окружения: `chrome.storage.local` в расширении, хранилище менеджера userscript-ов (`GM_getValue` / `GM_setValue`) в userscript, `localStorage` в userscript без менеджера. Если в userscript с менеджером хранилище менеджера пусто, а в `localStorage` есть настройки, сохранённые прежней версией, они MUST быть перенесены в хранилище менеджера при первом чтении и удалены из `localStorage`. Поля MUST быть скрыты как пароль. После сохранения MUST показываться статус «Сохранено», и новые значения MUST применяться без перезагрузки страницы.

#### Scenario: Сохранение ключа GIPHY
- **WHEN** пользователь вводит ключ GIPHY, нажимает «Сохранить» и открывает вкладку GIF
- **THEN** показана трендовая выдача GIPHY без перезагрузки страницы

#### Scenario: Перенос настроек из localStorage
- **WHEN** пользователь обновляет userscript в менеджере, а токен бота и ключи GIF были сохранены прежней версией в `localStorage` amo
- **THEN** на вкладке «Настройки» те же значения, импорт и поиск GIF работают без повторного ввода, а ключ настроек в `localStorage` amo удалён

#### Scenario: Настройки недоступны странице
- **WHEN** пользователь userscript с менеджером сохраняет токен бота
- **THEN** токена нет в `localStorage` amo
