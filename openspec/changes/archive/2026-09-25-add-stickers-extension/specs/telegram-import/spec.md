## Purpose

Позволяет перенести публичный стикерпак из Telegram в библиотеку amo stickers по ссылке, чтобы пользоваться привычными стикерами.

## ADDED Requirements

### Requirement: Разбор ссылки на пак
Система SHALL принимать ссылки вида `t.me/addstickers/<name>`, `t.me/addemoji/<name>`, те же ссылки с `https://` и доменом `telegram.me`, а также голое имя пака (латиница, цифры, подчёркивание). На другой ввод система MUST показать ошибку «Не понял ссылку».

#### Scenario: Полная ссылка
- **WHEN** пользователь вводит `https://t.me/addstickers/HotCherry`
- **THEN** импортируется пак `HotCherry`

#### Scenario: Некорректный ввод
- **WHEN** пользователь вводит `привет мир`
- **THEN** показана ошибка «Не понял ссылку. Нужна вида t.me/addstickers/Name»

### Requirement: Импорт через Bot API
Система SHALL получать состав пака и файлы стикеров через Telegram Bot API по токену бота из настроек. Без токена импорт MUST NOT начинаться, а пользователю MUST показываться ошибка «Укажите токен бота в настройках». Ошибка API (пак не найден, неверный токен) MUST показываться текстом ответа Telegram.

#### Scenario: Нет токена
- **WHEN** токен не задан и пользователь нажимает «Импорт»
- **THEN** показана ошибка «Укажите токен бота в настройках», запросов к Telegram нет

#### Scenario: Пак не существует
- **WHEN** пак с указанным именем не существует
- **THEN** показана ошибка из ответа Telegram, пак в библиотеку не добавлен

### Requirement: Конвертация всех типов стикеров
Каждый стикер пака SHALL сохраняться в библиотеку как GIF в соответствии с `sticker-conversion`: статичные — из WebP, анимированные — из `.tgs`, видео — из WebM. Эмодзи стикера MUST сохраняться вместе с ним.

#### Scenario: Смешанный пак
- **WHEN** импортируется пак со статичными и видео-стикерами
- **THEN** в библиотеке все стикеры пака, видео-стикеры анимированы

### Requirement: Прогресс и частичные сбои
Во время импорта система SHALL показывать полосу прогресса и статус ««<название>»: N/M». Вкладка пака MUST появляться после первого сконвертированного стикера. Ошибка одного стикера MUST NOT прерывать импорт остальных. После завершения система MUST открыть вкладку импортированного пака.

#### Scenario: Один стикер не сконвертировался
- **WHEN** один из 30 стикеров не удалось скачать или сконвертировать
- **THEN** импорт доходит до 30/30, в паке 29 стикеров

### Requirement: Повторный импорт
Пак SHALL идентифицироваться по имени в Telegram, стикер — по его уникальному идентификатору в Telegram. Повторный импорт того же пака MUST обновлять существующий пак, а не создавать дубликат.

#### Scenario: Импорт того же пака дважды
- **WHEN** пользователь импортирует пак, который уже есть в библиотеке
- **THEN** в панели вкладок по-прежнему одна вкладка этого пака, стикеры не задваиваются

### Requirement: Хранение токена
Токен бота MUST храниться только локально в хранилище настроек текущего окружения и MUST NOT передаваться никуда, кроме `api.telegram.org`.

#### Scenario: Сетевые запросы при импорте
- **WHEN** выполняется импорт
- **THEN** токен встречается только в запросах к `api.telegram.org`
