## Purpose

Определяет окружения, в которых работает расширение (браузерное MV3-расширение и userscript), а также единые правила сетевых запросов и хранения настроек в них.

## ADDED Requirements

### Requirement: Браузерное расширение
Система SHALL поставляться как Chrome MV3-расширение, которое запускается на страницах `https://*.amo.tm/*`, `http://localhost:3000/*` и `http://127.0.0.1:3000/*`. Расширение MUST запрашивать только разрешение `storage` и доступ к хостам GIPHY, KLIPY и Telegram API.

#### Scenario: Установка распакованного расширения
- **WHEN** пользователь загружает `dist/extension` как распакованное расширение и открывает web.amo.tm
- **THEN** в поле ввода появляется кнопка стикеров, в консоли страницы строка `[amo-stickers] started (extension)`

### Requirement: Сетевые запросы в обход CORS страницы
В расширении все запросы к внешним API и CDN SHALL выполняться из фонового service worker, чтобы не зависеть от CORS-заголовков сервисов. Ошибки HTTP MUST возвращаться в интерфейс с кодом статуса и началом тела ответа.

#### Scenario: Telegram без CORS
- **WHEN** Telegram API не отдаёт CORS-заголовки
- **THEN** импорт в расширении всё равно работает

### Requirement: Userscript
Система SHALL поставляться как самодостаточный userscript (`dist/amo-stickers.user.js`) с тем же поведением, что и расширение. Он работает в менеджерах userscript-ов (Tampermonkey и т. п.). Повторное подключение скрипта на той же странице MUST NOT создавать второй экземпляр.

#### Scenario: Запуск в менеджере userscript-ов
- **WHEN** пользователь устанавливает скрипт в Tampermonkey и открывает web.amo.tm
- **THEN** в поле ввода появляется кнопка стикеров, в консоли строка `[amo-stickers] started (userscript)`

#### Scenario: Двойное подключение
- **WHEN** скрипт подключён на странице дважды
- **THEN** у каждого поля ввода по-прежнему одна кнопка стикеров

### Requirement: Настройки
Система SHALL хранить ключ GIPHY, ключ KLIPY и токен Telegram-бота на вкладке «Настройки» в хранилище окружения: `chrome.storage.local` в расширении, `localStorage` в userscript. Поля MUST быть скрыты как пароль. После сохранения MUST показываться статус «Сохранено», и новые значения MUST применяться без перезагрузки страницы.

#### Scenario: Сохранение ключа GIPHY
- **WHEN** пользователь вводит ключ GIPHY, нажимает «Сохранить» и открывает вкладку GIF
- **THEN** показана трендовая выдача GIPHY без перезагрузки страницы
