## Purpose

Приводит любые исходные форматы стикеров к GIF: это единственный формат, который amo отправляет без перекодирования и с сохранением прозрачности.

## ADDED Requirements

### Requirement: Поддерживаемые входные форматы
Система SHALL конвертировать в GIF статичные изображения (PNG, JPEG, WebP), анимированные изображения (GIF, анимированный WebP), видео (WebM, в том числе VP9 с альфа-каналом, и MP4) и Lottie-анимации Telegram (`.tgs`, gzip JSON).

#### Scenario: Статичный WebP из Telegram
- **WHEN** на вход подаётся статичный WebP-стикер 512×512 с прозрачным фоном
- **THEN** на выходе однокадровый GIF с прозрачным фоном

#### Scenario: Анимированный стикер .tgs
- **WHEN** на вход подаётся `.tgs`-анимация
- **THEN** на выходе анимированный GIF с зацикленным воспроизведением

#### Scenario: Видео-стикер WebM
- **WHEN** на вход подаётся WebM-видео с альфа-каналом
- **THEN** на выходе анимированный GIF, прозрачные области видео прозрачны

#### Scenario: Неподдерживаемый файл
- **WHEN** на вход подаётся файл, из которого не удаётся извлечь ни одного кадра
- **THEN** конвертация завершается ошибкой с понятным текстом

### Requirement: Прозрачность
Система MUST сохранять прозрачность исходника: пиксели с непрозрачностью ниже 50% MUST становиться прозрачными в GIF, остальные непрозрачными. Кадры анимации MUST NOT накладываться друг на друга: каждый кадр очищается перед следующим.

#### Scenario: Анимация на прозрачном фоне
- **WHEN** конвертируется анимация объекта, двигающегося по прозрачному фону
- **THEN** в GIF нет следа от предыдущих кадров

### Requirement: Размер и вес
Кроме случая «GIF без перекодирования», система SHALL масштабировать результат так, чтобы большая сторона была не больше 512 px (родной размер стикеров Telegram), с сохранением пропорций, без увеличения мелких исходников. Если GIF получается тяжелее 2 МБ, система MUST перекодировать его с большей стороной 384, затем 320, затем 256 px, пока вес не уложится в лимит. Анимация MUST обрезаться до 4 секунд и не более 100 кадров.

#### Scenario: Стикер Telegram
- **WHEN** конвертируется стикер 512×512
- **THEN** результат имеет размер 512×512

#### Scenario: Большая картинка
- **WHEN** конвертируется изображение 2000×1000
- **THEN** результат имеет размер 512×256

#### Scenario: Тяжёлая анимация
- **WHEN** анимация в 512 px даёт GIF тяжелее 2 МБ
- **THEN** результат уменьшен до первой из сторон 384, 320, 256 px, при которой GIF не больше 2 МБ (или до 256 px, если лимит недостижим)

#### Scenario: Длинное видео
- **WHEN** конвертируется видео длиной 10 секунд
- **THEN** результат содержит только первые 4 секунды

### Requirement: Плавность и скорость анимации
Анимации (Lottie и видео) SHALL конвертироваться с частотой 25 кадров в секунду, если исходник не реже. Длительность GIF MUST совпадать с длительностью исходника (в пределах обрезки до 4 секунд), в том числе когда частота исходника ниже 25 fps.

#### Scenario: Lottie 60 fps
- **WHEN** конвертируется `.tgs` на 180 кадров при 60 fps (3 секунды)
- **THEN** GIF содержит 75 кадров по 40 мс, общая длительность 3 секунды

### Requirement: Точность цвета
Система SHALL строить палитру каждого кадра по полному цвету непрозрачных пикселей, без предварительного огрубления до 4 бит на канал; прозрачность занимает отдельный индекс палитры. Если без сглаживания средняя ошибка цвета кадра превышает 1 уровень из 255, система MUST применять упорядоченный дизеринг, не мерцающий между кадрами. Кадры с плоскими заливками MUST кодироваться без дизеринга.

#### Scenario: Градиент
- **WHEN** конвертируется изображение с плавным радиальным градиентом
- **THEN** в GIF нет видимых концентрических полос, средняя ошибка цвета не больше 2 уровней из 255

#### Scenario: Плоская заливка
- **WHEN** конвертируется стикер из однотонных заливок
- **THEN** дизеринг не применяется, вес GIF не растёт из-за шума

### Requirement: GIF без перекодирования
Если на вход подаётся GIF не больше 2 МБ и к нему не нужно применять подпись, система SHALL использовать исходный файл без изменений.

#### Scenario: Небольшой GIF
- **WHEN** пользователь загружает GIF размером 800 КБ без подписи
- **THEN** сохраняется исходный файл байт в байт

### Requirement: Отсутствие динамического исполнения кода
Конвертация MUST работать без `eval` и `new Function`, чтобы проходить CSP расширения.

#### Scenario: Сборка расширения
- **WHEN** собирается бандл расширения
- **THEN** в нём нет вызовов `eval(` и `new Function(`
