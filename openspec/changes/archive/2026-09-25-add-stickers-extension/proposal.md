## Why

В мессенджере amo нет стикеров и GIF: пользователи шлют картинки вручную, а привычные паки остаются в Telegram. Поэтому нужно стороннее расширение, которое выглядит как часть интерфейса amo и не требует изменений в самом amo. Прототип уже показал, что такой путь рабочий.

## What Changes

- Новая кнопка стикеров в поле ввода amo рядом с кнопкой эмодзи. По клику открывается попап, повторяющий по геометрии, стилю и анимации нативный попап эмодзи, в светлой и тёмной теме.
- Отправка стикера или GIF одним кликом через штатный путь amo: файл вставляется в поле ввода, затем нажимается «Отправить». Отправка блокируется, если в поле есть текст или вложения либо идёт редактирование.
- Поиск и трендовые GIF из GIPHY (гифки и прозрачные стикеры) и KLIPY по пользовательским API-ключам. Tenor не используется: Google перестал выдавать ключи с 13.01.2026 и закрыл API 30.06.2026. KLIPY совместим с Tenor v2.
- Импорт паков из Telegram по ссылке `t.me/addstickers/…` через Bot API, включая анимированные (`.tgs`) и видео-стикеры (`.webm`).
- Создание своих стикеров из картинки, GIF, видео или `.tgs` с необязательной подписью.
- Конвертация любых стикеров в GIF: amo перекодирует PNG и WebP в JPEG с белым фоном и без изменений пропускает только GIF.
- Локальная библиотека: паки, «Мои стикеры», недавние, удаление.
- Две сборки из одного ядра: Chrome MV3-расширение и userscript для менеджеров userscript-ов.

## Capabilities

### New Capabilities

- `composer-integration`: встраивание кнопки в поле ввода amo, попап, тема, открытие и закрытие, переустановка при перерисовке.
- `sticker-sending`: отправка стикера или GIF через штатный путь amo, предусловия и ошибки.
- `sticker-conversion`: приведение изображений, видео и Lottie к GIF с прозрачностью и лимитами размера.
- `gif-search`: поиск и тренды GIF и стикеров через GIPHY и KLIPY с подгрузкой.
- `telegram-import`: импорт пака Telegram по ссылке через Bot API с прогрессом.
- `custom-stickers`: создание своего стикера из файла с подписью и предпросмотром.
- `sticker-library`: локальное хранение паков, стикеров и недавних, удаление.
- `runtime-hosts`: окружения запуска (MV3-расширение, userscript), сетевые запросы и хранение настроек.

## Impact

- **Код:** новый проект `amo_msg_stickers` (TypeScript, esbuild), зависимости `gifenc` и `lottie-web` (light-сборка без `eval`).
- **amo web:** не меняется. Расширение опирается на разметку поля ввода (`aria-label="Send message"`, `aria-label="cancel edit"`, `div[contenteditable][aria-placeholder]`, tailwind-классы обёртки эмодзи). Изменения этой разметки в amo сломают встраивание.
- **Внешние сервисы:** GIPHY API, KLIPY API v2, Telegram Bot API. Нужны ключи пользователя и соблюдение требований к атрибуции. Тестовые ключи GIPHY и KLIPY ограничены 100 запросами в час.
- **Риск:** не проверено, остаётся ли GIF анимированным у получателя (сервер может отдавать перекодированную копию). От этого зависит ценность решения.
