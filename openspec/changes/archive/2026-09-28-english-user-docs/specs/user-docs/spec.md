## MODIFIED Requirements

### Requirement: Сайт доки
Дока SHALL публиковаться сайтом на GitHub Pages по адресу `https://mcar2107.github.io/amo_msg_stickers/`, собранным из
исходников в Markdown в репозитории. Изменение исходников доки в `master` MUST публиковаться без выпуска релиза. У сайта
MUST быть навигация по разделам, поиск по тексту и светлая и тёмная тема.

Дока SHALL быть на двух языках: русская — в корне сайта, английская — под `/en/` с тем же путём страницы
(`setup/gif-keys` → `/en/setup/gif-keys`). У каждой русской страницы MUST быть английская, и наоборот. В шапке MUST быть
переключатель языка, ведущий на ту же страницу на другом языке. Навигация, боковое меню, поиск и служебные подписи
сайта (оглавление, «назад» и «дальше», тема, страница «не найдено») MUST быть на языке страницы; поиск на странице одного
языка MUST NOT находить страницы другого. Английская дока MUST называть экраны, кнопки и поля amo stickers так, как их
показывает английский интерфейс. Скрины и видео у обоих языков MUST быть одни и те же файлы; подписи к ним — на языке
страницы. Сайт MUST NOT перенаправлять читателя по языку браузера: язык выбирает адрес.

#### Scenario: Правка доки
- **WHEN** в `master` попадает коммит, меняющий только исходники доки
- **THEN** сайт доки обновляется, новый релиз не создаётся

#### Scenario: Битая ссылка
- **WHEN** страница доки ссылается на несуществующую страницу доки
- **THEN** сборка сайта падает с указанием ссылки

#### Scenario: Английская страница
- **WHEN** читатель открывает `https://mcar2107.github.io/amo_msg_stickers/en/setup/telegram`
- **THEN** страница импорта из Telegram, навигация и боковое меню — на английском, скрины — те же, что у русской
  страницы

#### Scenario: Переключение языка
- **WHEN** читатель на русской странице установки для Firefox выбирает English в переключателе языка
- **THEN** открывается английская страница установки для Firefox

#### Scenario: Адреса русских страниц
- **WHEN** читатель открывает адрес русской страницы, опубликованный до появления английской доки
- **THEN** открывается та же русская страница

#### Scenario: Поиск на английском
- **WHEN** читатель английской доки ищет «token»
- **THEN** в результатах только английские страницы

### Requirement: Адреса страниц браузера
Адрес, который страница сайта открыть не может (`chrome://extensions`, `edge://extensions`, `browser://extensions` и
подобные), SHALL копироваться в буфер по клику, с отметкой «Скопировано» рядом — на английской странице «Copied». Без
доступа к буферу отметка MUST NOT появляться, адрес MUST оставаться видимым текстом, который можно выделить.

#### Scenario: Скопировать адрес страницы расширений
- **WHEN** пользователь нажимает `chrome://extensions` в таблице адресов на странице установки для Chromium
- **THEN** адрес в буфере обмена, рядом на полторы секунды появляется «Скопировано»

#### Scenario: Скопировать адрес на английской странице
- **WHEN** пользователь нажимает `edge://extensions` на английской странице установки для Chromium
- **THEN** адрес в буфере обмена, рядом на полторы секунды появляется «Copied»

### Requirement: README как вход в доку
README репозитория SHALL начинаться с описания для пользователя: что это, как выглядит, что умеет, — и вести на доку
ссылкой «Установить». Рядом MUST быть ссылка на английскую доку для читателя без русского. Сборка, проверки и
устройство для разработчика MUST идти после и не заслонять путь установки.

#### Scenario: Посетитель репозитория
- **WHEN** посетитель открывает страницу репозитория на GitHub
- **THEN** на первом экране README — описание, демо и ссылка на установку, а не команды сборки

#### Scenario: Посетитель без русского
- **WHEN** посетитель открывает README и не читает по-русски
- **THEN** на первом экране есть ссылка на английскую инструкцию по установке
