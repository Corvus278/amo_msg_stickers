## MODIFIED Requirements

### Requirement: Подсказка импорта
Над полем ссылки на пак система SHALL показывать подсказку на языке интерфейса: где в Telegram взять ссылку на пак,
какие стикеры конвертируются в GIF (статичные, анимированные `.tgs` и видео) и ссылку на страницу доки об импорте (в
новой вкладке). Ссылка MUST вести на страницу доки на языке интерфейса: из английского — на английскую, из русского — на
русскую.

#### Scenario: Где взять ссылку
- **WHEN** пользователь открывает экран «Добавить стикеры»
- **THEN** у импорта из Telegram сказано, где в Telegram скопировать ссылку на пак и какие стикеры конвертируются, и
  есть ссылка на инструкцию

#### Scenario: Инструкция по импорту
- **WHEN** пользователь нажимает ссылку на инструкцию у импорта
- **THEN** в новой вкладке открывается страница доки об импорте из Telegram

#### Scenario: Инструкция по импорту на английском
- **WHEN** интерфейс на английском и пользователь нажимает ссылку на инструкцию у импорта
- **THEN** в новой вкладке открывается английская страница доки об импорте из Telegram
