## Why

Интерфейс amo stickers бывает английским, а дока пользователя — только на русском: ссылки «Step-by-step instructions
(in Russian)» из подсказок ведут англоязычного пользователя на страницы, которые он не прочтёт, а установить
расширение без доки ему не по силам (issue #58). Адреса доки заложены под второй язык, теперь его пора добавить.

## What Changes

- Английская версия каждой страницы доки под `/en/`: главная, выбор окружения и установка для Chromium, Firefox,
  Safari и десктопа, ключи GIF, импорт из Telegram, обновление, частые вопросы, политика конфиденциальности. Адреса
  русских страниц не меняются.
- Переключатель языка в шапке сайта; у английской части свои навигация, боковое меню, поиск и служебные подписи темы
  (оглавление, «назад/дальше», тема, страница 404), отметка «Copied» у копируемых адресов браузера.
- Скрины и видео — те же файлы, что у русской доки, с русским интерфейсом; подписи к ним (`alt`) — на английском.
  Названия экранов и кнопок amo stickers в тексте — как в английском интерфейсе.
- Интерфейс на английском ведёт ссылками подсказок (ключи GIF, импорт из Telegram, настройки) на английские страницы
  доки, текст ссылок больше не говорит «in Russian»; русский интерфейс — на русские страницы, как сейчас.
- README ведёт и на английскую доку.
- Версия — минор: у пользователя английского интерфейса меняется, куда ведут ссылки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `user-docs`: сайт доки на двух языках — русский в корне, английский под `/en/`, переключатель языка; README ведёт на
  обе версии.
- `runtime-hosts`: ссылки подсказок «Настроек» ведут на страницу доки на языке интерфейса.
- `gif-search`: ссылка на инструкцию по ключам в режиме «GIF» без ключей — на странице доки на языке интерфейса.
- `telegram-import`: ссылка на инструкцию в подсказке импорта — на странице доки на языке интерфейса.

## Impact

- `docs/`: новые страницы `docs/content/en/**`, английский вариант общего фрагмента в `docs/content/_parts/`, конфиг
  `docs/.vitepress/config.mts` (локаль `en`), `docs/.vitepress/theme/CopyCode.vue`.
- Ядро: `src/core/userDocs.ts` (адрес страницы по языку), компоненты со ссылками на доку (`SettingsView`, `GifView`,
  `TelegramImport`), `src/core/i18n/messages.en.ts`; тест `tests/userDocs.test.ts`.
- `README.md`, `CLAUDE.md`, версия в `package.json`, `src/extension/manifest.json`, `build.mjs`.
- Зависимостей не добавляется.
