## MODIFIED Requirements

### Requirement: Агент в мире страницы
Внутренний путь отправки amo доступен только скриптам страницы, поэтому в мире страницы SHALL выполняться агент, который
умеет одно: отправить переданный ему файл отдельным сообщением в открытый чат amo — ответом на сообщение, если в поле
ввода этого чата активен ответ, — и после отправки снять этот ответ. Агент MUST NOT отдавать странице и вызывающей
стороне ничего, кроме статуса команды и причины отказа: ни код ядра, ни API менеджера, ни настройки, ни содержимое поля
ввода, ни сообщение, на которое отвечают. Команды агенту видны скриптам страницы; через агента страница MUST NOT
получать возможностей сверх тех, что у неё уже есть, — отправить файл в открытый чат ответом и снять ответ она может и
сама.

#### Scenario: Посторонняя команда
- **WHEN** скрипт страницы шлёт агенту команду в неверном формате
- **THEN** агент ничего не отправляет и не отвечает

#### Scenario: Ответ не раскрывает черновик
- **WHEN** агент отправил стикер при тексте в поле ввода и активном ответе на сообщение
- **THEN** в его ответах нет текста поля, вложений, настроек и сообщения, на которое отвечают, — только статус
