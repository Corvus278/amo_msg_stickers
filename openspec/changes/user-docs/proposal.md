## Why

Установка и настройка amo stickers — барьер для не-программиста (issue #50): в README три абзаца для разработчика,
без Яндекса, Edge, Opera, Firefox, Safari и десктопа; не сказано про переключатель «Разрешить пользовательские
скрипты» в Tampermonkey для Chrome, без которого скрипт молча не работает; userscript не обновляется сам; как получить
ключ KLIPY / GIPHY, токен бота и ссылку на пак — по строке в интерфейсе, а ссылка KLIPY ведёт не туда, где выдают
ключи. Регистрация в Chrome Web Store оплачена (публикация — #51), и дока нужна до неё: карточке стора нужна ссылка на
политику конфиденциальности.

## What Changes

- **Дока пользователя** на русском: исходники — Markdown в `docs/`, сайт собирает VitePress, публикация на GitHub
  Pages сама при изменении `docs/` в `master`. Разделы: установка (развилка по браузеру; для Chromium — вкладки
  «Chrome Web Store» / «Архив» / «Userscript»; userscript — через Tampermonkey, Violentmonkey и Safari (Userscripts) —
  с пометкой «без гарантий»; десктоп — «пока недоступно»), ключи GIF (KLIPY
  рекомендуется за выбор контента), импорт из Telegram от @BotFather до ссылки на пак, обновление, FAQ, политика
  конфиденциальности. Места скринов — заглушки, скрины добавит автор. Структура готова ко второму языку (#54).
- **Userscript обновляется сам:** боевая сборка пишет в заголовок `@updateURL` и `@downloadURL` на файл последнего
  релиза; `pnpm watch` — без них.
- **Архив расширения в релизе — с постоянным именем** `amo-stickers.zip`, чтобы у доки была прямая ссылка «скачать
  последнюю версию». **BREAKING** для ссылок на `amo-stickers-<версия>.zip` из релизов (внешних ссылок нет).
- **Подсказки в интерфейсе** на обоих языках: KLIPY первым в настройках и со ссылкой на Partner Panel; у ключей GIF,
  токена бота, импорта из Telegram и пустого режима «GIF» — ссылка на страницу доки; у импорта — где взять ссылку на
  пак. Адрес доки — в одном месте ядра. Английского текста доки пока нет: ссылка из английского интерфейса говорит, что
  инструкция на русском.
- **CI:** проверка сборки доки в PR (битые ссылки ломают сборку), workflow публикации на Pages.
- **README** — продающий: что это, демо, возможности, «Установить» на доку; сборка и проверки — свёрнуты.
- **Иконки:** у расширения и userscript — иконка amo stickers; кнопка расширения на панели меняет иконку по теме
  браузера.

## Capabilities

### New Capabilities

- `user-docs`: дока пользователя — состав разделов, установка по окружениям, настройка ключей и импорта, политика
  конфиденциальности, публикация сайта, README как вход в доку.

### Modified Capabilities

- `runtime-hosts`: userscript обновляется менеджером по ссылкам на последний релиз; экран «Настройки» — порядок
  полей (KLIPY первым), ссылки на выдачу ключей и на доку; иконки расширения и userscript, иконка кнопки по теме
  браузера.
- `gif-search`: подсказка режима «GIF» без ключей ведёт ещё и на страницу доки о ключах.
- `telegram-import`: подсказка импорта говорит, где взять ссылку на пак, и ведёт на страницу доки.
- `ci-cd`: постоянное имя архива в релизе; сборка доки проверяется в PR; публикация доки на Pages.

## Impact

- Код: `build.mjs` (заголовок userscript), `src/core/i18n/messages.{ru,en}.ts`, `SettingsView/`, `TelegramImport/`,
  `GifView/`, новый модуль адреса доки в `src/core/`; иконки и смена иконки кнопки — `src/extension/` (`manifest.json`,
  `actionIcon.ts`, `content.ts`, `background.ts`).
- Новое: `docs/` — отдельный пакет со своими `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml` и
  `tsconfig.json`, страницы в Markdown, `docs/.vitepress/` (конфиг и тема с вкладками); `.github/workflows/pages.yml`;
  правки `ci.yml`, `release.yml`, `.github/actions/setup` (ставит и зависимости доки).
- Зависимости: `vitepress`, `vitepress-plugin-tabs` — в `docs/package.json`, корневые `package.json` и
  `pnpm-lock.yaml` их не видят: обновление движка доки не требует подъёма версии продукта. В корне — только скрипты
  `docs:dev`, `docs:build`, `docs:preview` и проверка типов обоих проектов в `typecheck`.
- Конфиги: `.gitignore` / `.prettierignore` / eslint ignores для кэша и сборки VitePress.
- Разовое ручное действие: включить Pages в настройках репозитория (источник — GitHub Actions).
- Версия — минорный подъём: новое поведение для пользователя (автообновление, подсказки).
- Связано с #42: со встроенными ключами разделы про токен и ключ станут необязательными.
