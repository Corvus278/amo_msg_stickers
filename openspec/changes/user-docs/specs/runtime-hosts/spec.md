## MODIFIED Requirements

### Requirement: Настройки
Система SHALL хранить ключ GIPHY, ключ KLIPY и токен Telegram-бота на вкладке «Настройки» в хранилище окружения: `chrome.storage.local` в расширении, хранилище менеджера userscript-ов (`GM_getValue` / `GM_setValue`) в userscript, `localStorage` в userscript без менеджера. Поля MUST идти в порядке: ключ KLIPY, ключ GIPHY, токен Telegram-бота. Если в userscript с менеджером хранилище менеджера пусто, а в `localStorage` есть настройки, сохранённые прежней версией, они MUST быть перенесены в хранилище менеджера при первом чтении и удалены из `localStorage`. Поля MUST быть скрыты как пароль. После сохранения MUST показываться статус «Сохранено», и новые значения MUST применяться без перезагрузки страницы.

#### Scenario: Порядок полей
- **WHEN** пользователь открывает «Настройки»
- **THEN** сверху вниз идут ключ KLIPY, ключ GIPHY, токен Telegram-бота

#### Scenario: Сохранение ключа GIPHY
- **WHEN** пользователь вводит ключ GIPHY, нажимает «Сохранить» и открывает вкладку GIF
- **THEN** показана трендовая выдача GIPHY без перезагрузки страницы

#### Scenario: Перенос настроек из localStorage
- **WHEN** пользователь обновляет userscript в менеджере, а токен бота и ключи GIF были сохранены прежней версией в `localStorage` amo
- **THEN** на вкладке «Настройки» те же значения, импорт и поиск GIF работают без повторного ввода, а ключ настроек в `localStorage` amo удалён

#### Scenario: Настройки недоступны странице
- **WHEN** пользователь userscript с менеджером сохраняет токен бота
- **THEN** токена нет в `localStorage` amo

## ADDED Requirements

### Requirement: Автообновление userscript
Заголовок userscript из боевой сборки SHALL содержать `@updateURL` и `@downloadURL`, указывающие на файл userscript
последнего релиза: `https://github.com/mcar2107/amo_msg_stickers/releases/latest/download/amo-stickers.user.js`.
Userscript dev-сборки (`pnpm watch`) MUST NOT содержать этих директив: менеджер не должен заменять его версией из релиза.

#### Scenario: Вышла новая версия
- **WHEN** в Tampermonkey установлен userscript из релиза, а в репозитории вышел релиз с большей версией
- **THEN** проверка обновлений в Tampermonkey находит и ставит новую версию

#### Scenario: Dev-сборка
- **WHEN** разработчик ставит в менеджер userscript из `pnpm watch`
- **THEN** в его заголовке нет `@updateURL` и `@downloadURL`

### Requirement: Подсказки настроек
У ключа KLIPY подсказка на экране «Настройки» SHALL вести на страницу выдачи ключей Partner Panel
(`https://partner.klipy.com/api-keys`), у ключа GIPHY — на `https://developers.giphy.com/dashboard/`, у токена — на
@BotFather. У ключей GIF и у токена MUST быть ссылка на страницу доки с пошаговой инструкцией. Подсказки MUST быть на
языке интерфейса; пока нет доки на английском, ссылки из английского интерфейса MUST вести на русскую доку, а текст
ссылки MUST говорить, что инструкция на русском. Ссылки MUST открываться в новой вкладке.

#### Scenario: Где взять ключ KLIPY
- **WHEN** пользователь открывает «Настройки» и нажимает ссылку в подсказке ключа KLIPY
- **THEN** в новой вкладке открывается страница API-ключей Partner Panel KLIPY

#### Scenario: Подробная инструкция
- **WHEN** пользователь нажимает ссылку на доку у токена Telegram-бота
- **THEN** в новой вкладке открывается страница доки об импорте из Telegram

#### Scenario: Английский интерфейс
- **WHEN** интерфейс на английском, а пользователь нажимает ссылку на доку у ключей GIF
- **THEN** подсказка на английском, текст ссылки говорит, что инструкция на русском, открывается русская страница доки
  о ключах GIF
