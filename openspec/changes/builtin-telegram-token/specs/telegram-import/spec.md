## MODIFIED Requirements

### Requirement: Импорт через Bot API
Система SHALL получать состав пака и файлы стикеров через Telegram Bot API. Токен бота MUST браться из настроек, если
пользователь задал свой, иначе — встроенный токен сборки. Если нет ни своего токена, ни встроенного, импорт MUST NOT
начинаться, а пользователю MUST показываться ошибка «Укажите токен бота в настройках». Ошибка API (пак не найден,
неверный свой токен) MUST показываться текстом ответа Telegram; отказ встроенному боту показывается по требованию
«Отказ встроенного бота».

#### Scenario: Нет токена
- **WHEN** в сборке нет встроенного токена, свой токен не задан, и пользователь нажимает «Импорт»
- **THEN** показана ошибка «Укажите токен бота в настройках», запросов к Telegram нет

#### Scenario: Импорт без своего токена
- **WHEN** в сборке есть встроенный токен, свой токен не задан, и пользователь импортирует существующий пак
- **THEN** пак импортируется, запросы к Telegram идут со встроенным токеном

#### Scenario: Свой токен важнее встроенного
- **WHEN** в сборке есть встроенный токен, а пользователь задал свой
- **THEN** все запросы импорта идут со своим токеном пользователя

#### Scenario: Пак не существует
- **WHEN** пак с указанным именем не существует
- **THEN** показана ошибка из ответа Telegram, пак в библиотеку не добавлен

### Requirement: Хранение токена
Свой токен бота MUST храниться только локально в хранилище настроек текущего окружения. Встроенный токен MUST NOT
показываться в «Настройках» и MUST NOT записываться в хранилище настроек: поле токена в «Настройках» пусто, пока
пользователь не задал свой. Любой токен — свой или встроенный — MUST NOT передаваться никуда, кроме `api.telegram.org`.

#### Scenario: Сетевые запросы при импорте
- **WHEN** выполняется импорт
- **THEN** токен встречается только в запросах к `api.telegram.org`

#### Scenario: Настройки без своего токена
- **WHEN** в сборке есть встроенный токен, а пользователь открывает «Настройки», не задав свой
- **THEN** поле токена пустое, и после «Сохранить» в хранилище настроек токен пустой

## ADDED Requirements

### Requirement: Отказ встроенного бота
Если импорт идёт со встроенным токеном, а Telegram отвечает отказом бота — HTTP 401 (токен недействителен) или HTTP
429 (превышен лимит запросов), — система SHALL показывать на языке интерфейса ошибку, что встроенный бот недоступен и
можно указать свой токен бота в настройках, вместо текста ответа Telegram. Отказ со своим токеном пользователя MUST
показываться как прежде — текстом ответа. Другие ошибки (пак не найден, сбой сети) MUST NOT подменяться этой ошибкой.

#### Scenario: Встроенный токен отозван
- **WHEN** импорт идёт со встроенным токеном, а Telegram отвечает на запрос пака HTTP 401
- **THEN** в строке статуса ошибка, что встроенный бот недоступен и можно указать свой токен в настройках

#### Scenario: Свой токен неверный
- **WHEN** импорт идёт со своим токеном пользователя, а Telegram отвечает HTTP 401
- **THEN** в строке статуса ошибка с ответом Telegram, без подсказки про встроенного бота

#### Scenario: Пак не найден на встроенном токене
- **WHEN** импорт идёт со встроенным токеном, а пака с таким именем нет
- **THEN** показана ошибка из ответа Telegram, а не ошибка недоступности встроенного бота
