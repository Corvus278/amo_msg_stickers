# amo stickers

Стикеры и GIF для amo web: кнопка в инпуте рядом с эмодзи, попап по клику, отправка по клику на стикер.

- GIF: поиск GIPHY (гифки и прозрачные стикеры) и KLIPY, нужны API-ключи. Tenor API Google закрыл 30.06.2026, KLIPY — совместимая замена от бывшей команды Tenor.
- Импорт паков из Telegram по ссылке `t.me/addstickers/…` через Bot API, нужен токен любого бота.
- Свои стикеры: картинка, GIF, видео или `.tgs` → GIF, можно добавить подпись.
- Недавние, паки и удаление хранятся в IndexedDB на домене amo.

## Как отправляется стикер

Публичного API для отправки сообщений у amo нет, поэтому стикер отправляется так же, как это сделал бы пользователь:

```
blob → File(image/gif) → paste в contenteditable → вложение → click [aria-label="Send message"]
```

**Почему всё конвертируется в GIF:** amo перекодирует PNG и WebP в JPEG с белым фоном, а GIF проходит без изменений. Прозрачность у GIF 1-битная, поэтому края грубее, чем в Telegram.

Если в поле ввода есть текст, вложения или идёт редактирование, отправка блокируется, иначе стикер ушёл бы вместе с ними.

## Сборка

```bash
pnpm i
pnpm build             # dist/extension/* и dist/amo-stickers.user.js
pnpm watch             # пересборка при изменениях
```

## Проверки

```bash
pnpm lint              # eslint + typecheck + prettier --check параллельно
pnpm lint:fix          # eslint --fix
pnpm format            # prettier --write
pnpm typecheck         # tsc (TS 7, пакет typescript-native)
pnpm test              # vitest, проект unit
```

Pre-commit (husky) гоняет lint-staged, typecheck и тесты по изменённым файлам.

## Установка

### Chrome / Яндекс / Edge

`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → `dist/extension`.
Затем откройте попап → ⚙ и введите ключи.

### Tampermonkey и другие менеджеры userscript-ов

Установите `dist/amo-stickers.user.js`. Ключи вводятся так же: попап → ⚙.

## Стенд

`dev/harness.html` повторяет разметку поля ввода amo. Для стилей сохраните CSS страницы web.amo.tm из DevTools в `dev/amo.css` (в git не лежит). Вставка и «Отправить» в стенде замоканы.

```bash
python3 -m http.server 8777 -b 127.0.0.1
open http://127.0.0.1:8777/dev/harness.html
```
