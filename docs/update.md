# Обновление

Как обновлять amo stickers, зависит от способа установки.

## Расширение из Chrome Web Store

Расширение пока на проверке в Chrome Web Store. Когда его опубликуют, браузер будет обновлять его сам — ничего делать
не нужно.

Если сейчас у вас расширение из архива, после публикации его можно заменить расширением из магазина. Магазин ставит
его как новое расширение, поэтому ключи GIF и токен бота придётся ввести заново.

## Расширение из архива {#archive}

Архив сам не обновляется: браузер не знает, откуда брать новую версию.

1. Скачайте новый архив по той же ссылке:
   [amo-stickers.zip](https://github.com/Corvus278/amo_msg_stickers/releases/latest/download/amo-stickers.zip) — это
   всегда последняя версия.
2. Удалите всё содержимое папки расширения, саму папку оставьте. Распаковка поверх старых файлов оставила бы файлы,
   которых в новой версии уже нет.
3. Распакуйте новый архив в ту же папку.
4. На странице расширений (например, `chrome://extensions`) нажмите «Обновить» вверху страницы или значок обновления
   на карточке amo stickers.
5. Перезагрузите вкладку amo.

<!-- скрин: img/update/extensions-reload.png — страница расширений: кнопка «Обновить» и значок обновления на карточке amo stickers -->

::: warning Папка — та же
Новую версию распаковывайте в ту же папку, что и старую. Расширение из другой папки браузер считает новым
расширением, и ключи GIF и токен бота придётся вводить заново.
:::

Установленная версия видна на карточке amo stickers на странице расширений, последняя — на странице
[релизов](https://github.com/Corvus278/amo_msg_stickers/releases/latest).

## Userscript

Tampermonkey сам проверяет обновления скрипта — по умолчанию раз в сутки — и ставит новую версию. Проверить сразу
можно из меню значка Tampermonkey: пункт проверки обновлений скриптов (в английском интерфейсе — «Check for userscript
updates»). Новая версия заработает после перезагрузки вкладки amo.

<!-- скрин: img/update/tampermonkey-check-updates.png — меню значка Tampermonkey, пункт проверки обновлений скриптов -->

::: warning Один раз — переустановить
Скрипт, поставленный до появления этой инструкции, сам не обновится: в нём ещё нет адреса, откуда брать новую версию.
Поставьте скрипт один раз заново по ссылке
[amo-stickers.user.js](https://github.com/Corvus278/amo_msg_stickers/releases/latest/download/amo-stickers.user.js) —
менеджер предложит обновить установленный amo stickers. Дальше обновления будут приходить сами.
:::

В менеджерах без гарантий — Violentmonkey, Userscripts в Safari — автообновление не проверяется. Если новая версия
не пришла, поставьте её вручную по той же ссылке.
