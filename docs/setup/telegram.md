# Импорт из Telegram

Пак стикеров из Telegram можно добавить в amo stickers целиком: стикеры станут GIF и появятся в ленте отдельным
разделом. Конвертируются статичные, анимированные (`.tgs`) и видеостикеры.

Для импорта нужен свой Telegram-бот: amo stickers скачивает пак через Bot API, а без токена бота Telegram файлы
стикеров не отдаёт. Бота достаточно создать один раз — добавлять его в чаты и что-то в нём настраивать не нужно.

::: warning Токен — секрет
Токен бота даёт полное управление ботом: с ним кто угодно сможет писать от имени бота и менять его. Не пересылайте
токен в чатах и не показывайте на скриншотах.

amo stickers хранит токен только в вашем браузере и отправляет его только в Telegram (`api.telegram.org`). Если токен
всё же попал к кому-то, выпустите новый: в @BotFather отправьте команду `/revoke`, выберите бота и вставьте новый токен
в «Настройки» вместо старого.
:::

## 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) — официальный бот Telegram для создания ботов — и нажмите
   кнопку запуска внизу чата (или отправьте `/start`).
2. Отправьте команду `/newbot`.
3. Введите имя бота — любое, например `amo stickers`: бот нужен только для импорта.
4. Введите имя пользователя бота — латиницей, цифрами или `_`, оно должно заканчиваться на `bot`, например
   `ivan_amo_stickers_bot`. Если имя занято, @BotFather попросит другое.

<!-- скрин: img/setup/botfather-newbot.png — чат с @BotFather: команда /newbot, имя и имя пользователя бота -->

## 2. Скопируйте токен

В ответ @BotFather пришлёт сообщение с токеном — строкой вида `1234567890:AAH…`. Скопируйте токен целиком, без пробелов
по краям.

<!-- скрин: img/setup/botfather-token.png — сообщение @BotFather с токеном нового бота, токен замазан -->

Если сообщение потерялось, токен можно получить заново: отправьте @BotFather команду `/mybots`, выберите бота и
нажмите «API Token».

## 3. Вставьте токен в «Настройки»

1. Откройте amo и наведите курсор на кнопку стикеров в строке ввода или нажмите на неё.
2. Внизу панели нажмите «Настройки».
3. Вставьте токен в поле «Токен Telegram-бота (для импорта)» и нажмите «Сохранить». Внизу панели появится «Сохранено».

<!-- скрин: img/setup/settings-token.png — экран «Настройки» amo stickers, поле «Токен Telegram-бота (для импорта)» -->

## 4. Скопируйте ссылку на пак {#pack-link}

**Нажмите на стикер из пака в чате Telegram, в окне пака откройте меню «⋮» и выберите «Копировать ссылку».**

Путь одинаковый в приложении Telegram на компьютере, в веб-версии и на телефоне; в некоторых приложениях меню
обозначено «…», а не «⋮». На телефоне ссылку на пак, который у вас уже добавлен, можно скопировать и из настроек:
«Настройки» → «Стикеры и эмодзи» → меню «⋮» рядом с паком → «Копировать ссылку».

Ссылка выглядит так: `https://t.me/addstickers/Имя`. Подойдёт и ссылка на пак эмодзи (`t.me/addemoji/Имя`) или одно
имя пака — часть ссылки после последней `/`.

<!-- скрин: img/setup/telegram-pack-link.png — окно пака в Telegram, открытое меню с пунктом «Копировать ссылку» -->

## 5. Импортируйте пак

1. В amo stickers откройте режим «Стикеры» и нажмите «+» справа от вкладок разделов — откроется экран «Добавить
   стикеры».
2. В разделе «Импорт из Telegram» вставьте ссылку в поле и нажмите «Импорт».
3. Дождитесь конца импорта: внизу панели идёт счёт стикеров, например «Имя пака: 12/40», а в конце — «Пак «Имя пака»
   добавлен». Пока идёт импорт, панель не закрывается, если увести с неё курсор.

<!-- скрин: img/setup/telegram-import.png — экран «Добавить стикеры»: ссылка на пак в поле импорта и счёт стикеров -->

Пак появится отдельной вкладкой в режиме «Стикеры». Стикеры каждого пака конвертируются один раз при импорте — дальше
они отправляются сразу.

## Если не получилось

- **«Укажите токен бота в настройках»** — токен не сохранён: вернитесь к шагу 3 и нажмите «Сохранить».
- **«Не понял ссылку. Нужна вида t.me/addstickers/Name»** — в поле не ссылка на пак. Скопируйте её заново по шагу 4.
- **Ошибка со словом «Telegram»** — Telegram не принял токен или не нашёл пак. Проверьте, что токен скопирован
  целиком, и что пак открывается по ссылке в самом Telegram.

Другие вопросы — в разделе [«Частые вопросы»](../faq).
